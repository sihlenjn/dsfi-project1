## Project Overview

My first project using **Quarto and GitHub**, developed as an introduction to GitHub and version control. It includes basic exercises and experiments with creating and rendering Quarto documents.

## Tools Used

- **R** – Programming language.
- **Quarto** – Creating and rendering documents.
- **GitHub** – Version control and project management.

## Project Contents

- `addition.qmd` – Basic addition exercise.
- `multiplication.qmd` – Basic multiplication exercise.
- `index.qmd` – Main Quarto document.
- `_quarto.yml` – Quarto project configuration.
- `docs/` – Rendered project output.

## Learning Objectives

- Getting familiar with Quarto and GitHub.
- Creating and rendering `.qmd` documents.
- Understanding basic Git and GitHub workflows.
- Learning how to organise and publish a project using GitHub.
